06 / CÓDIGOCRUD + DADOS
COMO OS PRODUTOS SÃO SALVOS

Estado local e persistência.

const persist = async (next) => {
  setProducts(next);
  await AsyncStorage.setItem(
    STORAGE_KEY,
    JSON.stringify(next)
  );
};

const save = async (form) => {
  const next = editing
    ? products.map((item) =>
        item.id === editing.id
          ? { ...form, id: item.id }
          : item
      )
    : [...products, { ...form, id: Date.now().toString() }];

  await persist(next);
};

O mesmo fluxo cria um produto novo ou atualiza um produto existente.

07 / CÓDIGOEVENTOS
BUSCA E FILTROS

Interações controladas pelo estado.

const [category, setCategory] = useState('Todos');
const [search, setSearch] = useState('');

const visibleProducts = products.filter((product) => {
  const matchesCategory =
    category === 'Todos' || product.category === category;
  const query = search.toLowerCase();

  return matchesCategory &&
    (!query || `${product.name} ${product.brand}`
      .toLowerCase().includes(query));
});

Cada digitação ou seleção atualiza o estado e recalcula os produtos exibidos.
